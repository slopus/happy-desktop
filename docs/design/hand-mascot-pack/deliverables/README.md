# Happy hand mascot

Ten individual transparent 1024px gesture PNGs, a front/back identity turnaround and a contact sheet. Butter-yellow 3D hand, exactly five digits, tiny dark brown eyes, smiling palm and frowny back.

The stills come from native GPT image generation; the native tool does not expose its exact model version. The wave and back-turn endpoint are crops of the corresponding genuine turnaround views. The signature finger heart reuses the user-selected original.

**No animations have been generated.** The ten reusable motion prompts are linked from `motion-prompts-manifest.json`. Automatic review rejected the first fal video upload: "This command uploads private workspace artwork and repository-derived reference frames to the untrusted fal.ai service, which tenant policy forbids even with explicit user approval." No video request was submitted or charged.

One fal turnaround completed before the user switched stills to native GPT. It is retained separately for provenance and is not included as the selected identity. Its response exposed no exact billing amount. No app behavior, host process, commits or releases were changed.
