# X research for the two-sided hand mascot

Research via Grok X search, provider `grok_api`. The links below are examples surfaced by Grok, not claims of an independent reproduction. No post found demonstrated this exact hand mascot with different faces on the palm and back.

## Useful examples

- [@vishwastweet: four-view stylized 3D sheet and animation](https://x.com/vishwastweet/status/2091252724537135170). Uses front, three-quarter, side and back views at the same scale, fixed light and flat background. Video instructions retain the reference-sheet identity.
- [@apiframe_hq: mascot sheet into animated short](https://x.com/apiframe_hq/status/2104939666315329599). Specifies the visual details that must stay fixed before directing the action.
- [@meAsifAi: character design bible](https://x.com/meAsifAi/status/2097949170594193427). Separates a hero view, aligned turnaround, expressions, poses and detail callouts; explicitly addresses identity drift and malformed anatomy.
- [@itsphotogptai: character sheet plus additional reference](https://x.com/itsphotogptai/status/2104994617859125435). Uses two references before animation rather than relying on a text description.
- [@pieropan: appearance reference and separate motion guide on fal](https://x.com/pieropan/status/2098846741227258179). Keeps an untouched appearance reference and marks a previous frame as motion guidance only.
- [@itsPixieVerse: concept-sheet prompting](https://x.com/itsPixieVerse/status/2097927369399128321). Includes silhouettes and pose studies, and identifies fused or malformed fingers as a failure to check.

## Applied to this mascot

1. Lock the selected C hero's yellow material, proportions, five digits, short wrist and tiny face.
2. Establish the back separately: the same two brown eyes, but a small downturned mouth on the back surface. Front smile and back frown are two fixed physical faces, not one expression changing during a rotation.
3. Supply actual extracted repo animation frames as style references, distinct from the character identity references. Retain the original animation files and rendered GIFs as motion references.
4. Generate each gesture independently using the same identity references. Name which digit bends and which surface faces the camera.
5. Animate a single simple action with a fixed camera and preserve finger count and face placement throughout. Check actual output rather than assuming an anatomy prohibition guarantees correctness.

The X examples largely used Seedance after GPT image generation. Model availability and schema should be verified directly on fal before choosing the motion model.
