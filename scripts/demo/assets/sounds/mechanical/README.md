# Mechanical keyboard recordings

These 32 `keypress-*.wav` files are the isolated keypress recordings from
[Keyboard Soundpack #1 (Typing and Single Keystrokes)](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes)
by unicaegames (OpenGameArt submission, 2021).

- License: **CC0 1.0**, as stated on the source page.
- Keyboard: Cherry KC 1000.
- Recording: Shure SM7B; post-processed with iZotope Neutron 2 by the author.
- Source archive: `unicae_games_keyboard_soundpack_1_0.zip`.

The recorder cycles through 29 recorded transients for ordinary keys, with two
separate samples assigned to spaces and one to Enter. The source archive also
contains human typing takes, but the demo uses the isolated files so each cue
remains individually placed against the typed characters.
